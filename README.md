# Puzzle Adventure 
A 2D puzzle game built with Python and Pygame where you interact with NPCs, solve puzzles, explore and uncover clues with the help of quirky, wise and mysterious characters.

## Features
- Player movement and exploration.
- Scripted AI-style NPCs with personalities; wise, funny, neutral.
- Dynamic dialogue interactions.
- Puzzle elements.
- Simple but extendable 2D graphics.
- Easy to run.

## Tech Stack
- **Python 3**
- **Pygame**
