# 🕹️ Adventure Quest: Maze of Secrets

A **fun Python game built with Pygame** where you explore, talk to NPCs, search bushes for a hidden key, unlock a magical portal, and survive a **randomly generated maze** to prove your skill.

---

## 🎮 Gameplay Features

* **Player Movement**
  Use arrow keys (`↑ ↓ ← →`) to move around.

* **NPCs with Personalities**

  * **Guide** → Blue circle with a green triangle hat 🧙‍♂️ (wise dialogue).
  * **Joker** → Yellow circle with a red nose 🤡 (funny dialogue).

* **Hidden Key Mechanic**

  * Bushes 🌿 are scattered randomly.
  * One of them hides a **key** 🗝️.
  * Walk into the right bush to reveal it.

* **Locked Gate & Portal**

  * A locked **door** blocks your path.
  * Once you find the key, the door turns into a glowing **purple portal**.
  * Walk into the portal and press **`E`** to enter.

* **Random Maze Challenge**

  * Every time you enter, a **new maze is generated**.
  * You must find the exit while respecting wall boundaries.
  * Successfully escaping returns you to the main world.

* **Dialogues & Interactions**

  * Walk into NPCs to trigger a dialogue box.
  * Dialogues are randomly chosen based on the NPC’s personality.

---

## 🛠️ Requirements

Make sure you have **Python 3.8+** installed.
Install dependencies via pip:

```bash
pip install pygame
```

---

## ▶️ How to Run

1. Clone this repository or copy the files.
2. Run the main file:

   ```bash
   python main.py
   ```
3. Play the game and explore! 🎉

---

## ⌨️ Controls

* **Arrow Keys** → Move around.
* **E** → Enter the portal when prompted.
